# 🛍️ ShopNova – Online Shopping App

ShopNova is a modern Java-based ecommerce web application developed to provide a smooth and interactive online shopping experience. The project focuses on responsive UI/UX, category-wise product management, secure authentication, and dynamic product filtering for better user engagement.

## ✨ Features

- 🔐 User Login & Registration
- 🛒 Add to Cart Functionality
- 📂 Category-wise Product Display
- 🔍 Product Search & Filtering
- 📱 Responsive Modern UI
- ⚡ Dynamic Product Rendering
- 💳 Ecommerce Simulation
- 🎨 Attractive Dark Theme Design

## 🧑‍💻 Technologies Used

- ☕ Java
- 🌱 Spring Boot
- 🗄️ MySQL
- 🌐 HTML5
- 🎨 CSS3
- ⚙️ JavaScript
- 🧩 JSP & Servlets
- 🔗 JDBC

## 📸 Project Overview

The application allows users to explore products from multiple categories such as Electronics, Fashion, Grocery, Beauty, Sports, and Home & Living with a clean and user-friendly shopping interface.

## 🚀 Objective

To develop a scalable and user-friendly ecommerce platform that simplifies online shopping through modern web technologies and efficient product management.
